# ボードゲームのルールブック

ボードゲームの遊び方を掲載する静的Webサイトです。GitHub Pagesで公開します。

## 公開ページ

- [フェルミ推定思考のルールブック](https://keng0o.github.io/boardgame/fermi/)

「フェルミ推定思考」は、チームで数字を推定し、カードを小さい順に並べる協力ゲームです。掲載内容は基本ルール、配置の例、勝敗条件、遊ぶ前に採用を相談する補足です。

## ファイル構成

- `fermi/index.html`: ルールブック本文、配置図、目次リンク。
- `fermi/styles.css`: 配色、文字、レイアウトの表示スタイル。スマートフォン表示と印刷に対応します。
- `fermi/assets/card-front.png`: 「日本の書店の店舗数」をお題にした表カードの見本画像。
- `fermi/assets/card-deck.svg`: 山札の図の旧素材。現在のページでは使用しません。
- `index.html`: サイトのトップからルールブックへ移動するページ。
- `.nojekyll`: HTMLをJekyllで変換せず、そのまま公開するためのファイル。

外部ライブラリやビルド処理は不要です。

## ローカルで確認する

Python 3が使える環境で、リポジトリのルートから実行します。

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8080/fermi/` を開きます。

## 更新と公開

GitHubリポジトリは `keng0o/boardgame` です。GitHub Pagesの公開元を `main` ブランチのルートディレクトリに設定します。

本文を更新した後は、スマートフォン幅とデスクトップ幅で表示と目次リンクを確認し、変更対象のファイルだけをコミットして `main` にpushします。GitHub Pagesのデプロイ完了後、公開URLで更新内容を確認してください。
